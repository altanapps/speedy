03 — Typography

05 — Surfaces & Materials

Native blur. Adapts free.

The trade overlay is .regularMaterial. Not a solid panel, not a custom blur — the native NSVisualEffectView so it picks up vibrancy, light-mode adaptation, Reduce Transparency, and accent color shifts at no cost.

Reduce Transparency. When the user enables Reduce Transparency in System Settings → Accessibility, the overlay falls back to bg.elevated (#18181C) with a 1px separator-strong border. The native material handles this automatically; we only need to pre-test the fallback contrast.

08 — Trade overlay

320pt of frictionless trade.

The overlay is fixed at 320pt wide. Variable height — minimum 248pt (entry), grows for swap dropdown, shrinks for confirm/done. Anchors to the bottom-right of the cursor at mouseUp; flips horizontally if it would clip the screen edge.

State · entrydefault

User has highlighted, hotkey held, market matched. All controls active. ⌘⏎ submits.

State · routing700ms

Optimistic — overlay swaps to a centered spinner with caption "routing order". Cancellable with esc for the first 300ms (window before order leaves the wire).

State · filled2s

Green check, summary line, auto-dismiss after 2s. Click to keep open and view receipt.

Anchor logic. The overlay's top-left anchors at (mouseUp.x + 8, mouseUp.y + 12). If x + 320 > screenBounds.maxX - 16, flip to (mouseUp.x - 320 - 8, …). If y + height > screenBounds.maxY - 16, anchor above the cursor instead. Never clips, never scrolls.

09 — Motion

80–180ms ease-out. No bounce.

Trader tools should not feel like games. Springs add ambiguity about "is the action committed?" Linear ease-out of 80–180ms is fast enough to feel instant, slow enough to be perceived, and unambiguous about commit timing.

SwiftUI · animation
extension Animation {
    static let speedyFast = .easeOut(duration: 0.08)
    static let speedyBase = .easeOut(duration: 0.12)
    static let speedySlow = .easeOut(duration: 0.18)
}

// Usage
.animation(.speedyBase, value: isVisible)

// Reduce Motion → all become .linear(duration: 0)
No spring. Period. Reject any .spring(), .bouncy, or .smooth in code review. The only allowed easing is .easeOut with the three durations above. Spinners use .linear. That's the entire motion vocabulary.

10 — Accessibility

Trades require precision. Precision requires accessibility.

System settings respected
  • Reduce Transparency → material falls back to bg.elevated with separator border
  • Reduce Motion → all easing becomes duration: 0. Spinner becomes a static caption.
  • Increase Contrast → labels switch to α 100% / α 80% / α 60% tier; separator opacity doubles
  • Differentiate Without Color → side selector adds ▲/▼ glyph; price changes annotated with arrows
  • Larger Text → labels and buttons scale; price stays fixed (always-readable)
Keyboard model
⌃ heldarms Speedy on next selection
⌃Spacearm/disarm toggle
tabcycle through size presets
b / sswitch buy/sell (or yes/no)
⌘⏎submit order
escdismiss / cancel within window
VoiceOver
  • Overlay announces as: "Speedy. Match: Polymarket prediction. Fed cuts rates at May 7 meeting. Yes 62 cents, up 4 cents."
  • Buy button announces: "Buy Yes for 100 dollars. Activate to submit. Command-Return."
  • Match excerpt is exposed as accessibilityLabel = "matched from quote: …"
  • State changes (routing, filled) post .announcement notifications.
Touch / cursor targets

Minimum cursor target: 28×28 pt (buttons, segmented cells). Minimum tap target if Speedy ships on iPad: 44×44 pt. Spacing between actionable elements ≥ 4pt.

11 — Voice & copy

Terse. Unambiguous. Never cute.

Speedy is in the path of money. Every label needs to be defensible the moment a trade goes wrong. No emoji. No clever metaphors. Read like a Bloomberg terminal mixed with a stopwatch.

Glossary · canonical terms
arm / armedSpeedy is listening for a selection. Hotkey held or toggled.
matchA tradable market identified from selected text.
overlayThe 320pt panel containing the trade UI. Not "popup," not "modal."
excerptThe selected text fragment shown in the overlay header.
venueThe market source (Polymarket, NYSE, Hyperliquid, etc.). Always shown.
fillAn executed order. "Filled at 62¢," not "Bought at 62¢."

12 — Do / Don't

Edge cases the design system has opinions about.

DO
PRICE DISPLAY
$71,240.00

Tabular figures. Same width on every digit. No jitter on tick.

DON'T
PRICE DISPLAY
$71,240.00

Proportional figures. The "1" is narrower than the "0". Layout reflows on every tick.

DO
SUBMIT BUTTON

States the action, the size, and the shortcut. No mystery.

DON'T
SUBMIT BUTTON

"Confirm" doesn't tell the user what they're confirming. Use the verb + amount.

DO
OVERLAY ENTRANCE
120ms ease-out, opacity 0→1, translateY 4pt → 0. Predictable commit timing.
DON'T
OVERLAY ENTRANCE
300ms spring(damping: 0.6). Bouncing into a trade UI is a usability anti-pattern.
